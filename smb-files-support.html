SMB Files Support

Reach your network shares from iPhone, iPad & Mac

SMB Files talks to anything that shares files over SMB — a Synology or QNAP NAS, a Windows PC, a Mac with File Sharing on, or a Samba server on a Raspberry Pi. The most common fixes are below.

Connecting

What do I put in the Host field?

The server's IP address (for example 192.168.1.50) or its network name (for example nas.local). Leave the port at 445 unless your server is set up on a different one.

It says it can't connect

Work through these in order:

  • Make sure your iPhone or iPad is on the same network as the server — SMB is a local-network protocol and will not reach a server across the internet unless you are on a VPN.
  • Check that file sharing is switched on at the server: Windows → File and Printer Sharing; Mac → System Settings → General → Sharing → File Sharing; NAS → the SMB service in its control panel.
  • Confirm the username and password by connecting from a computer first.
  • iOS asks once for permission to find devices on your local network. If you declined, turn it back on in Settings → SMB Files → Local Network.

I connect, but no shares are listed

That usually means the account signed in successfully but has no shares assigned to it. Check on the server that your user has access to at least one shared folder. Administrative shares hidden with a $ are not listed.

Which SMB versions are supported?

SMB 2 and SMB 3. Very old servers limited to SMB 1 are not supported — SMB 1 has been deprecated for years and is switched off by default on modern systems for good security reasons.

Files & transfers

How do I download a file?

Tap and hold a file, then choose Download. Folders open with a single tap, and the back arrow walks you up the tree.

What does the info button show?

Connection diagnostics for the session you are in — the server and share you are connected to, the account in use, and a running log of the operations the app has performed. It is the first place to look when something is not behaving.

Is my data encrypted?

Traffic between your device and your server uses SMB's own protections, and your credentials are stored in the device Keychain. Because SMB is a local-network protocol, your files never travel over the public internet or through any server of ours. See the Privacy Policy.

How do I remove ads?

Open Settings → SMB Files Pro. One-time purchase, no subscription, removes all ads forever, on all your devices via universal purchase. Already bought it? Tap Restore Purchases.

Still stuck?

Send details of your server (make and model, or the operating system it runs) and the exact error message the app showed — it usually points straight at the fix. The in-app connection info view logs the operations that ran and is helpful to include.
