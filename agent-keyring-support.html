Agent Keyring — Support

Free & open source (MIT)

Getting help

File an issue on GitHub: github.com/jbaker00/agent-keyring/issues. Please include your macOS version and the output of agent-keyring doctor (it prints no secrets).

Common problems

  • "gcloud not found" in the app: install Google Cloud SDK, or set the path explicitly in Settings (gear icon). GUI apps do not inherit your Terminal PATH; the app searches common SDK locations and your login shell.
  • Local list is empty: local secrets live under keychain service agent-keyring. If you deleted demo keys in Terminal, an empty list is correct — click Add to create one.
  • Shared commands fail: run gcloud auth application-default login, confirm gcloud config get-value project, and enable secretmanager.googleapis.com on your own project.
  • AWS/Azure/OCI errors: each backend uses that cloud's CLI and login (aws configure / az login / oci setup config) plus its vault config — see the error text and agent-keyring doctor.

Security questions

See the open security review in the repository (docs/SECURITY-REVIEW.md). The headline: Agent Keyring removes plaintext secrets from files and prompts; it does not protect against malicious code already running as your user.
